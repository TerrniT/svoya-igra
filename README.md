# Своя игра

Викторина на Vue 3: поле с категориями и номиналами, админка вопросов и комнаты для нескольких устройств.

```bash
pnpm install
pnpm dev
```

Локально откройте игру по адресу в сети (не `localhost`), чтобы телефоны открыли QR. На Vercel достаточно ссылки с продакшена.

- `/` — комната или игра на одном экране
- `/join/1234` — вход по коду
- `/game` — поле
- `/admin` — категории и вопросы

Комната живёт во вкладке ведущего (WebRTC через Trystero / Nostr). Ведущий не закрывает эту вкладку, пока идёт игра. Серверный WebSocket не нужен — статический деплой на Vercel подходит.

## Vercel

Статический SPA: игроки находят друг друга через публичные Nostr-релеи, дальше данные идут напрямую по WebRTC. Серверных функций нет.

1. Импортируйте репозиторий в [Vercel](https://vercel.com/new) (GitHub → TerrniT/svoya-igra).
2. Preset **Vite** подхватится сам: `pnpm install` / `pnpm build` / `dist`. Node 22 (см. `.nvmrc`).
3. Переменные окружения не нужны. `vercel.json` уже переписывает Vue Router-пути на `index.html`.

После деплоя откройте продакшен-URL, создайте комнату и присоединитесь с телефона по коду или QR. Ведущий не закрывает вкладку, пока идёт игра.
